WHAT IS IT

A smarter way to keep every washroom fresh and hygienic

The Smart Washroom Monitoring System by Techno Exponent is an IoT solution for washrooms in malls, schools, hospitals and offices. A sensor node installed inside each washroom continuously tracks odor trend, humidity and stale air, and turns every bad-smell event into an assigned, tracked and verified cleaning task.

  • Spots rising odor in real time, washroom by washroom
  • Dispatches the right cleaner automatically on WhatsApp
  • Gives admins a weekly view of hygiene performance
KEY FEATURES

Everything you need for smarter washroom hygiene

Sensing, alerting, dispatching and verification in one connected system.

Continuous Air Sensing

A BME688 sensor tracks gas, humidity and temperature, so the system follows odor trend and stale air around the clock.

Learns Each Washroom's Baseline

Baseline logic learns the normal smell pattern of every washroom, so alerts are based on how that specific space usually behaves.

Live Critical Alerts

When bad smell rises above the threshold, the operations dashboard shows a live, high-priority alert with the exact washroom location.

Automatic Cleaning Tasks

A cleaning task is created automatically and assigned to a cleaner the moment the odor threshold is crossed. No manual dispatching.

WhatsApp Notifications

The assigned cleaner gets a WhatsApp message with the washroom, the issue and its priority, and can accept the task right from the chat.

Verified Resolution

After cleaning, the odor score falls, the task is marked resolved and the washroom status returns to normal on the dashboard.

HOW IT WORKS

From bad smell to fresh washroom in 4 steps

  1. 01

    Monitor

    A sensor node installed inside the washroom continuously tracks odor trend, humidity and stale air, and sends live data to AWS IoT.

  2. 02

    Detect & alert

    When bad smell rises above the learned threshold, the dashboard shows a live critical alert for that washroom.

  3. 03

    Assign & notify

    A cleaning task is created automatically and a WhatsApp notification is sent to the assigned cleaner.

  4. 04

    Clean & resolve

    The cleaner accepts the task, reaches the washroom and cleans it. The odor score falls and the task is marked resolved.

What is the Smart Washroom Monitoring System?

It is an IoT solution by Techno Exponent for washrooms in malls, schools, hospitals and offices. A sensor node tracks odor trend, humidity and stale air, and the system raises live alerts, creates cleaning tasks automatically, notifies cleaners on WhatsApp and gives admins a weekly performance dashboard.

What does the sensor measure?

Each washroom has a sensor node built on an ESP32-S3 controller and a BME688 sensor. The BME688 tracks gas, humidity and temperature, and the controller sends this live data to AWS IoT.

How does it decide when a washroom needs cleaning?

Baseline logic learns the normal smell pattern of each washroom. When the odor level rises above the threshold, the dashboard shows a critical alert and a cleaning task is created automatically.

How are cleaning staff notified?

As soon as a task is created, the assigned cleaner receives a WhatsApp notification with the washroom location, the issue and its priority. The cleaner can accept the task and head to the washroom.

How do we know the problem was fixed?

After cleaning, the sensor shows the odor score falling. The task is marked resolved and the washroom status returns to normal on the operations dashboard.

What reports do admins and facility heads get?

A weekly dashboard shows the number of odor alerts, resolved and pending tasks, average response time, daily alert trends, the most affected washrooms, response time by day and cleaner performance. Reports can be exported.
